# Working In This Repo

## Source of truth

The code is current. [AGENTS.md](../../AGENTS.md) and the docs it links are
background. If a doc and the code disagree, trust the code and leave the doc
alone unless the user asks you to fix it.

## Questions vs judgment calls

- **Implementation and architecture calls are yours.** Make them, state the
  key ones in plain language, and keep going.
- **Business intent is not yours to invent.** If a change depends on a product
  rule the code and docs don't already settle (who may do what, what a status
  means, what a user should see), ask. One question at a time.

## Current vs planned

`docs/product/` describes what existed when it was written. Only
[target-direction.md](../product/target-direction.md) describes what doesn't
exist yet. Don't present planned work as built.
